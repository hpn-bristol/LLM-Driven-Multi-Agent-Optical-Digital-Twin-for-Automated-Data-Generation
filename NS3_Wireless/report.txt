Dataset structure:
- scenarios.csv: merged flow-level wireless KPI records with compact columns and rich JSON fields.
- summary.json: machine-readable multi-run aggregate statistics.
- report.txt: human-readable dataset report.
- artifacts.zip: original prompts, scenarios, reviews, generated ns-3 scripts, logs, and raw results.

Rich JSON fields:
- scenario_request_json: per-row task, target access, CPE, flow, and sweep parameters.
- ns3_config_json: engine, command parameters, selected branch, and generated-output files.
- branch_config_json: Wi-Fi, LTE/EPC, or LiFi-surrogate branch configuration.
- semantic_features_json: task-relevant wireless semantic indicators.
- validation_json: simulator compatibility and LiFi-surrogate interpretation flags.

LiFi note:
Stock ns-3.44 does not include a built-in LiFi model. LiFi rows are produced by the generated
single-file ns-3 script using an idealized standard ns-3 access-link surrogate.
